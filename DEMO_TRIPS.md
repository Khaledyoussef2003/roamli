# ROAMLI Demo Trips

This mock-mode build intentionally includes five different trip profiles so the product can be tested before live APIs are connected.

- Dubai Luxe Weekend — planned premium couple trip, exact hotel/stay route anchor, fine dining, shopping/nightlife, external reservation flow, weather/offline tags.
- Ibiza Friends Escape — friends, relaxed/nightlife, villa entered by address, beaches, rental car/taxi, saved restaurants and external booking behavior.
- Italy Local Journey — couple, local/authentic, moderate budget, multi-city Rome/Florence/Venice, changing stays/train travel, food/culture/photography.
- Prague Smart Budget — solo, budget/packed, walking + public transport, culture/local food, cost visibility and a Needs attention state.
- Mykonos Summer Draft — friends, luxury/relaxed, no accommodation selected yet, beaches/wellness/nightlife, Add stay to improve routes behavior, call fallback where no booking URL exists.

The same mock dataset is surfaced through Home, Planner, My Trips, Saved Trips, Saved Places, Collections, itinerary overview/day view/map/costs, and route-anchor states.
